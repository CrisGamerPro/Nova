# NovaGUI (For Windows)
If you dont want to install Python to use Nova then this is the perfect solution!
> At least for Windows lol

## Installation
NovaGUI is compiled into an EXE file using PyInstaller so you can run it without Python installed on your system.
Go to releases and download the NovaGUI.zip file, there youll find this:

```
NovaGUI
  ↳ launcher.exe
      nova.exe
      Code
        ↳ interpreter.exe
           editor.exe
```

Run launcher.exe if you want to run a fast update check, or simply open nova.exe.

## Features
- Builtin editor: A simple code editor for nova.
- Run `.nova` files by specifying its path instead of running `python nova.py file.nova`.
> Soon the builtin editor will have a syntax check to improve the experience.
